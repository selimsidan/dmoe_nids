# results

Small result files copied from `OUTPUT_ROOT` by `python scripts/sync_results.py`:
per-run tables and manifests (`runs/`), cross-seed summaries (`summary/`) and
the split description (`splits/split.json`). Paths inside are relative to
`OUTPUT_ROOT`. Column definitions: [docs/RESULTS_SCHEMA.md](../docs/RESULTS_SCHEMA.md).

Empty until the paper campaign has run. Per-row prediction files are too large
for the repository; TODO: link to the release asset that holds them.
